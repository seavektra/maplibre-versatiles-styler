# SeaVektra fork

This is SeaVektra's fork of [versatiles-org/maplibre-versatiles-styler](https://github.com/versatiles-org/maplibre-versatiles-styler).
ChartManager's admin UI embeds it on its Basemaps pages: the styler bound to a basemap, the mapping editor, and the headless build behind Publish and Export style.

## Branches

- `main` tracks upstream `main` and carries no changes of ours.
- `seavektra` holds our changes and is what we release.

## Changes from upstream

| Change                                                                        | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Named exports `LayerMappingEditor` and `buildBasemapStyle` (`src/index.ts`)   | The control stays the default export. With named exports the UMD global `VersaTilesStylerControl` is the module object, so a script tag uses `VersaTilesStylerControl.default`; ChartManager imports the ES module and is unaffected.                                                                                                                                                                                                                                                                                                    |
| `.github/workflows/seavektra-release.yml`                                     | Builds a tag `v<upstream version>-sv.<n>` and attaches `dist/maplibre-versatiles-styler.js` (ES module) and its `.d.ts` to a GitHub release.                                                                                                                                                                                                                                                                                                                                                                                             |
| `.github/workflows/release.yml` ignores `v*-sv.*` tags                        | Upstream's workflow publishes to npm; our tags must never reach it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `archives` option: a **PMTiles file** provider in Tile sources                | ChartManager offers the PMTiles archives it serves. The picked file is the map's only tiles (no satellite, elevation or land cover from a server) and the map moves to its bounds; fonts and icons still come from `origin`. Another archive of Terrarium elevation tiles can be picked under **Elevation**, which makes hillshade and terrain available.                                                                                                                                                                                |
| Zoom ranges for layer groups (`src/lib/style/zooms.ts`)                       | Min/max zoom fields per group in the Layers menu, with ‹ › step arrows (`InputNumber` `stepper`) and an ⓘ per group listing its layers with their zooms, fades and the zooms their tile layer is in the tiles at, applied to the built style, kept in the link (`zooms=`) and in an exported style's `metadata["seavektra:layerZooms"]`, which Import reads back. A min zoom moves a layer's opacity fade-in by as much as it moves the layer's start. `@versatiles/style` has no zoom option for groups.                                |
| `persist` option                                                              | Keeps the whole hash (style, options, zoom ranges, sources, view) in `localStorage` and restores it when the page opens without a hash.                                                                                                                                                                                                                                                                                                                                                                                                  |
| Map inspector (`InspectPanel.svelte`, `src/lib/style/inspect_tiles.ts`)       | In inspect mode (⌖) a click opens a docked panel listing the tile features at that point by tile layer: for each, the style layers that draw it with group, zoom range, fade and editable colours, and the features no style layer drew, with why (group hidden, outside the zoom range, label not placed, or no style layer for it).                                                                                                                                                                                                    |
| Export **For: SeaVektra app** (`src/lib/transfer/app_style.ts`)               | The app draws the base map from a PMTiles archive it bundles. The app form writes the base map source as `url: "{BASE_MAP_URL}"` with no tiles or zoom range (MapLibre reads them from the archive; a `maxzoom` in the style would override the archive's own), leaves out land cover, satellite and elevation and their layers, maps label fonts to the app's Open Sans, and leaves glyphs and sprite to the app.                                                                                                                       |
| **Online above** a PMTiles file (`src/lib/style/online.ts`)                   | The app bundles a low-zoom planet archive and reads deeper zooms from a server. With **Online above** on, the PMTiles file provider adds the VersaTiles server's vector tiles (same schema) from a zoom on (**Online from zoom**, default one above the archive's maxzoom): each base map layer is drawn from the archive or from the server by its source role (below), as MapLibre has no source that falls back by zoom. The split is kept in the link and in `metadata["seavektra:online"]`; the app export keeps the online source. |
| Source roles per layer group (`src/lib/style/roles.ts`, `role_status.ts`)     | Each layer group gets a role: **auto** (offline if the group starts below the switch zoom, else online), **offline** (the PMTiles archive), **online** (the VersaTiles server) or **switch** (archive below the split zoom, server above). The Layers menu warns where a role cannot work, such as a switch group that draws twice or an online group that starts below the switch zoom; warnings never block export. Roles are kept in the link and in `metadata["seavektra:layerRoles"]`.                                              |
| Switch layers: overlap, fade-in and preload (`src/lib/style/fade.ts`)         | Only switch layers get an `-overlap` copy that stays drawn while the `-online` copy fades in, so the zoom change shows no gap, and the online source is preloaded only when a switch layer exists. Layers with another role are drawn once from their source.                                                                                                                                                                                                                                                                            |
| Offline fallback by global state `online` (`src/lib/style/online.ts`)         | The style declares the root state `online` (default true). `-online` copies show while it is true; `-fallback` copies read the archive while it is false, so the app can keep drawing without a network. **Preview without network** in the preview simulates it.                                                                                                                                                                                                                                                                        |
| Chart anchor and over-chart groups (`src/lib/style/chart_anchor.ts`)          | An empty `seavektra-chart` layer marks where chart layers go. Groups ticked **Over chart** (default: rivers, buildings, airport, sites) move after the anchor with their copies, so they draw over the chart; the anchor and groups are kept in `metadata["seavektra:chart"]`.                                                                                                                                                                                                                                                           |
| Layer mappings (`src/lib/style/layer_mapping.ts`)                             | A basemap's tiles can have layers the theme does not draw, or need groups the theme lacks. A mapping (`{ version: 1, groups, moves, merges, labels, groupFilters, filters, newLayers }`) adds and renames layer groups, moves and merges style layers between groups, narrows groups and layers with filters and adds new style layers on tile layers the theme leaves out. Entries that cannot apply (a missing layer or group, a cycle) are skipped with a warning and change nothing.                                                 |
| `basemap` option: the styler bound to a basemap (`src/lib/style/basemap.ts`)  | ChartManager styles one stored basemap at a time. With `basemap: { name, tileset, elevation?, mapping, state, onsave }` the styler shows the basemap's name and its fixed PMTiles file, applies the mapping, keeps its state in memory instead of the URL hash, and a **Save** button hands the state (`{ version: 1, params }`) to `onsave`. New style layers get colour, width, opacity and dash fields; the state carries their paint and new groups' visibility.                                                                     |
| `LayerMappingEditor` (`src/lib/mapping/`)                                     | The basemap Edit screen in ChartManager edits the mapping without a map: `new LayerMappingEditor({ container, definition, tileset, origin?, onchange })` lists the theme's groups and style layers with the mapping applied, and has forms to rename, filter (rows built from the tileset's fields), move, merge and add. `getDefinition()` returns the mapping, `setTileset()` switches the file.                                                                                                                                       |
| `buildBasemapStyle` (`src/lib/publish/build.ts`, `src/lib/style/pipeline.ts`) | ChartManager publishes and exports a basemap's style without opening the styler. `buildBasemapStyle({ state, mapping, tileset, elevation?, origin, name })` returns `{ style, warnings }`: the same app style the styler's export gives, through the pipeline the styler itself uses. It reads the PMTiles headers and metadata over `fetch`, so it needs no map and no `addProtocol`; a tileset that cannot be read throws, elevation or online tiles that cannot be read are warnings.                                                 |

## Merging upstream

```bash
git remote add upstream https://github.com/versatiles-org/maplibre-versatiles-styler.git  # once
git fetch upstream
git switch seavektra
git merge upstream/main
npm ci && npm run check:release && npm run build
```

Also fast-forward `main` to `upstream/main`.

## Releasing

1. On `seavektra`, tag `v<upstream version in package.json>-sv.<n>`, starting `<n>` at 1 for each upstream version, e.g. `v3.0.2-sv.1`.
2. `git push origin <tag>`, or create the tag in GitHub's "Draft a new release" form with target `seavektra`. The SeaVektra release workflow checks, builds and attaches the bundle to the release.
3. In ChartManager: `scripts/update-versatiles-styler.sh <tag>`, then commit the vendored file.
